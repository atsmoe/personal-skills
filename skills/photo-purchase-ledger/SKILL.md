# 照片转材料采购明细

支持 Codex、agy/Gemini；采用当前环境可用工具。默认按本次日期和受影响区域工作，把全量机器检查留在程序中，模型只接收需要判断的证据。

## 始终保留的约定

- 本项目根目录 `E:/codex/wuliao`，正式表 `10月份置景材料采购明细表.xlsx`。本项目在线表是主表；本地跟随在线，修改正式本地文件前备份。其他项目以用户指定文件及主表为准。仅更新本地的请求不自动操作在线表。
- 日期目录 `1001` 等表示月日，年份从原表或原始证据确认。图片按 Windows CreationTime 排序；收据后接对应实物照，结合图像内容配对。同时间图片不能按哈希文件名武断排序。
- 收据用于识别，照片列只嵌实物照。有依据的字段填全，未知字段留空，不写“待确认”，不猜数。保留票面结算尾差，不倒改单价凑总额。
- 同一个月持续追加同一张总表；在线可能有其他人实时修改。目标是我们手里的采购全部有对应记录；其他人增补保留并另列清单，不要求在线每条都有本地来源。保留手动日期归属、历史底色和原有照片。集装箱压缩机归 10月3日，透明玻璃胶归 10月4日。
- 新明细与汇总默认白底，不自行加核对色。恢复颜色须凭修改记录；首次读取前已有的颜色不能据此判断修改人。
- 辅助资料保存在所处理日期的 `.work_MMDD`；正式表保留原路径。最终说明完成状态、当天及累计金额；核对或同步时另列在线额外条目，本地未找到来源不等于已确认修改人。不报收据/明细/照片数量，不把来源清单或核对说明塞入正式表。

## 按任务加载

只读需要的参考，不一次读完所有文件；优先直接运行脚本，必要时才读其源码。

| 本次任务 | 加载资料与范围 |
|---|---|
| 新增一天、继续同一天 | [incremental.md](references/incremental.md)，写表时再读 [workbook.md](references/workbook.md)；只识别本次新增、变更、未核实来源 |
| 对照照片核对 | [reconciliation.md](references/reconciliation.md) 和增量参考；按用户日期核对覆盖，差异报告不自动改账 |
| 统一或修复格式 | workbook 参考；程序全表检查格式，修改授权区域，预览受影响区域；无需重识别采购照片 |
| 在线同步或回写本地 | [online-workbook.md](references/online-workbook.md)；先取得最新在线状态，再按差异操作 |

## 工作循环

1. **看最新状态**：用程序读当前表的表头、末尾、日期块、合并和汇总；有可用快照时比较内容及布局。模型只接收摘要、变更行范围、异常和必要的小范围数据。快照缺失时建立机器基线，不自动重读全月图片。
2. **按需看证据**：新增或改变的收据/实物照必须看原图。旧记录仅在有原图校验及哈希依据、相关表格区域未变化时复用；旧 OCR/JSON 或“文件未变”本身不证明识别正确。数字模糊则旋转、放大对应区域，仍不确定的字段留空。
3. **做局部修改**：写前刷新在线状态，重定位并复查本次缺项；他人新改动纳入最新基线，已存在的采购不重复追加。只补授权日期缺项或改授权格式，不用旧本地表覆盖在线。并发处理见 online-workbook 参考。新增格带边框，共用实物照对应的 J 列纵向合并并居中；日常不重写全表样式。
4. **验收再记录**：程序核验历史值/公式/图片保留、金额口径、全表行高及受影响图片几何；模型查看新增或变化区域与末尾。本地保存后用 Excel 正常打开确认无需修复；在线另做样式/合并/结果读回。仅在验收通过后记录已核实来源及目标区域。未完成项目明确保留，不能当作已处理。

## 格式底线

本项目宋体黑色，正文/表头/汇总 12 pt、标题 16 pt，标题/表头/汇总加粗；全表水平垂直居中、换行，G/H 金额两位小数，黑色细线真实边框。在线明细至少 120 px，当前明细/表头/汇总统一 120 px，对应本地 90 pt；标题保留实际高度。照片按真实单格或合并区等比居中，上下至少 8 px、左右至少 14 px。细节及保包规则见 workbook 参考。

## 工具与验收边界

- [ledger_context.py](scripts/ledger_context.py)：只读扫描最新 XLSX/指定日期照片，生成观察快照，返回有限摘要与变化范围；不判断照片是否已识别，也不证明在线状态最新。
- [inventory.py](scripts/inventory.py)：生成 CreationTime 顺序及文件哈希清单。
- [check_xlsx.py](scripts/check_xlsx.py)：检查缓存金额、错误和可选图片几何；不计算公式，不证明字体或在线版验收通过。
- 修改 XML 须保留兼容命名空间、关系、公式及原始图片对象；文件可解析不等于 Excel 可正常打开。遇到占用先保留结果在辅助目录，不强关用户应用。
