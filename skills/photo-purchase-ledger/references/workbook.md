# 表格和工具

> 规范版本：v2.4.0

## 从当前模板确定结构

先读取用户选定工作表、表头、照片列和实际日期块。下面是新建采购表的可选示例，不能作为所有项目的固定结构；列位置、标题/表头行由当前模板及项目配置决定。

| 示例列 | 内容 | 处理 |
|---|---|---|
| A | 序号 | 继续最后材料序号，跳过汇总 |
| B | 日期 | 年份有证据，按模板日期类型与显示格式 |
| C | 材料名称 | 收据为基础，实物可补全；不丢弃已识别部分 |
| D | 规格 | 型号、尺寸、品牌、颜色有据才填 |
| E/F | 数量/单位 | 数字可含小数，单位沿来源 |
| G/H | 单价/金额 | 数字、金额通常两位小数；数量×单价与票面一致可用公式，有结算尾差则保留已核实票面金额 |
| I | 场景 | 来源未说明留空 |
| J | 实物照片 | 只嵌实物照，同组多条共用照片时纵向合并实际照片列 |

字体、字号、加粗、对齐、换行、行高和列宽沿用用户已确认模板；要求统一格式时按该项目基准检查全表，日常只写新行与差异区域。新格带真实边框，不能靠编辑器网格线。保留历史底色，新明细/汇总默认白底，不自行加核对色。长文字完整显示，金额不能因在线默认格式丢失小数位。没有可用字体时说明实际替代，并重新检查文字与图片尺寸。

例如原表汇总采用 A:G 合并、H 金额，则新增汇总沿用；原照片列 J 且同组占第4至6行，则用 J4:J6 并在完整区域居中。这些只是示例位置，不固定工作表名称或行号；合并不跨采购组、日期或小结。复制样式后另查真实合并关系。

## 追加与金额

同一收据按原顺序逐项录入，不混并或重复计入。分别识别数量、单价、行金额，不能由总额倒算单价覆盖原图；有据的结算尾差保留，并在辅助记录说明。

例如新增明细第29至44行、金额列H时，当天小结可用 `SUM(H29:H44)`；累计仅汇总全部明细，不再次包含各日小结。必须按最新表重定位，不能照抄示例行号；多人在线写前刷新，保留他人插入内容。

保留用户手动日期归属及历史采购，不因票面日期不同自动跨日挪动、删除或回退；汇总公式应纳入实际归属范围。只处理用户授权日期，继续同一天时依据当前明细、来源记录与原图匹配，避免重复追加。

## 工具选择

- 采用当前环境提供的表格工具；需要运行时时通过环境依赖工具获取。不可假设某台设备的 Python、Node 或软件目录。
- Gemini/agy 可使用可用 Python（如 openpyxl + Pillow）或其他可靠编辑器，不要求 Codex MCP。读取现有表，不从空白重建；禁止 `data_only=True` 加载后保存导致丢公式。
- 编辑前检查对象类型。WPS DISPIMG、rich-data 单元格图片、宏、签名或扩展对象不一定能被 openpyxl 保留；选保留对象的工具，不能用有损重建覆盖。
- 将公式改为固定票面金额后读回确认旧公式已移除；缓存变化不等于公式移除。核验历史内容、公式、合并、样式及图片。
- openpyxl 不重算公式。用 Excel、LibreOffice 或计算工具刷新；工具缺失时独立核算新增明细，并说明重算/兼容性未验证，不把空缓存当0。`check_xlsx.py --expect <单元格>=<金额>` 仅验缓存。
- 按当前 agent 的实际发现规则安装单个技能，确认加载路径及版本；不绑定模型版本，不要求注册到旧机器的目录。只同步用户当前实际使用的安装副本，不自行改全局工具配置。

## 来源记录

在选定辅助目录保存日期、收据原相对路径、实物照路径、SHA-256、采购组、核实字段、未解决项及目标区域。未知数值用 `null`，不用0；来源索引和说明不是新增业务列。沿用已有结构，不为了结构统一改写原票据记录。复用条件见 [incremental.md](incremental.md)。

## 实物照片布局

读取保存文件的真实列宽、行高和合并区域。默认字体数字宽度7 px时可用 `floor(字符列宽×7+5)` 换算宽度，其他字体校准；不能固定照片宽度。按96 DPI基准 `90 pt = 120 px` 只是单位换算示例，不是项目固定高度。

沿用已确认的统一明细行高，包括无图行和合并区域各行；标题、表头及汇总按各自模板。不单独拉高某个有图行。合并高度是各行高度之和；尺寸变化后重算受影响图片。

留白按项目配置（默认左右14 px、上下8 px，可调）。设可用尺寸 W/H 为容器减去两侧留白，原图 w/h，缩放 `s = min(W/w, H/h)`；图片尺寸为 round(w×s)、round(h×s)，偏移为容器剩余尺寸的一半。等比完整展示、水平垂直居中、不越界、不遮边框。保存后遍历全部相关 DrawingML 部件和锚点；不能只检查 drawing1.xml。几何脚本可检 oneCell/twoCell 锚点，其他模式须单独验证。

## 保留工作簿包

只改授权样式；保留公式与缓存、合并、原始图片字节/锚点、关系、列宽及行高。工具不能保留对象时采用保留原 OOXML 部件的增量补丁。XML 保留兼容命名空间声明，包括 `mc:Ignorable` 引用的全部前缀；写 ZIP 复制 ZipInfo，不修改正在读取的源条目。核验仅授权部件变化，再正常打开确认没有修复提示。接收设备没有 Excel 时在其目标软件验证，并明确尚未完成的 Excel 兼容检查，不能凭结构解析声称通过。
